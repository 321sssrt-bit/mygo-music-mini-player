# 提供可选的用户级「守候模式」解决宿主冷启动惰性加载

`egoist/mygo-music` 冷启动时（`internal/app/sources.go` 的 `boot`）仅初始化当前选中音源插件的 JS 运行时，其余已启用插件在用户打开插件页或进入「设置 > 插件」前不会执行任何代码。为避免用户每次重启 `mygo-music` 后都必须手动点开一次本插件才能呼出迷你悬浮窗，我们决定在插件设置中提供显式可选的「守候模式」（写入当前用户的系统登录启动项，关闭开关时立即移除）：守候进程在未检测到 `mygo-music` 运行时不创建任何窗口、保持休眠，检测到宿主进程出现后自动进入工作状态。
